# WEBTECH-Projekt Julius Weckowski, Kenny Spannuth

- Gym Tracker. Man soll jeden Tag tracken können wo man trainiert hat oder auch nicht. Jeweils mit den Übungen, Satzanzahl, Wiederholungen und Gewicht/Zeit.

- TechStack
-   Backend: Java + Spring Boot
-   Frontend: TypeScript + Vue.js
-   Datenbank: Managed PostgreSQL
